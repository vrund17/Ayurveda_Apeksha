## 🚀 How to Run the Website Locally

You can launch the website in 2 ways:

### Option 1: Using Python (Recommended)
Open a terminal in this directory (`c:\Users\Devstree\Documents\demo`) and run:
```bash
python server.py
```
Then open your web browser and navigate to:
**`http://localhost:8000`**

### Option 2: Directly in Browser
Double-click `index.html` to open it in Chrome, Edge, Safari, or Firefox.
