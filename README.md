## 💻 Local Development & Deployment

### Running Locally:
```bash
python server.py
```
Open **`http://localhost:8000`** in your web browser.

### Deploying to GitHub / Netlify / Vercel:
The project is built with static web standards (`HTML5`, `Tailwind CSS CDN`, `Lucide Icons CDN`, and vanilla JavaScript `app.js`). It requires no build step and can be hosted anywhere.
